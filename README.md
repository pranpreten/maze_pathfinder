# 미로 길찾기

격자에서 BFS와 A*의 탐색 과정과 최단 경로를 비교하는 데스크톱 프로그램입니다. Python 표준 라이브러리만 사용합니다.

## 실행

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe maze_visualizer.py
```

가상환경이 이미 있으면 마지막 명령만 실행하면 됩니다. 활성화된 가상환경에서는 `python maze_visualizer.py`로 실행합니다. 추가 패키지가 없어 requirements.txt는 비어 있습니다.

## 사용

1. 시드를 입력하고 `미로 생성`을 누르거나 `빈 격자`에서 시작합니다. 시드를 비우면 무작위 미로를 만듭니다.
2. 벽 그리기, 벽 지우기, 출발점, 도착점 모드로 격자를 편집합니다.
3. BFS 또는 A*를 골라 `탐색 실행`을 누릅니다. 속도 슬라이더로 한 번에 표시할 탐색 칸 수를 조절합니다.
4. `두 알고리즘 비교`로 같은 미로의 탐색 칸 수, 최단 이동 수, 계산 시간을 비교합니다.
5. 미로를 JSON으로 저장하고 다시 불러올 수 있습니다.

초록색 S가 출발점, 빨간색 E가 도착점, 파란색이 탐색한 칸, 노란색이 최단 경로입니다. 편집하거나 새 탐색을 시작하면 이전 애니메이션을 취소합니다.

## 알고리즘

21 × 31 격자에서 상하좌우 이동만 허용하며 모든 이동 비용은 1입니다. BFS는 큐를 이용해 거리 순서대로 탐색합니다. A*는 현재까지 이동 거리와 도착점까지의 맨해튼 거리 합을 우선순위로 사용합니다. 같은 조건에서 두 알고리즘의 최단 이동 수는 같습니다. 서로 다른 최단 경로를 고를 수 있고, A*가 항상 더 빠르다는 보장은 없습니다.

미로는 깊이 우선 방식으로 통로를 만든 후 일부 벽을 추가로 열어 생성합니다. 계산 시간에는 화면 애니메이션을 포함하지 않습니다. 작은 격자에서 측정한 시간은 실행마다 변하므로 성능 벤치마크로 일반화하지 않습니다.
